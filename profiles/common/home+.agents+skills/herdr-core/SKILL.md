name: herdr-core
description: "Use herdr-core, whose CLI is `hc`, for background or long-running work, coordinating or reading other agents and terminals, working on another machine, or shaping the Herdr window (spaces, tabs, layouts, mods)."
---

`hc` is the herdr-core CLI. It is not `herdr`, the older terminal multiplexer, which has its own command and skill. Use `hc` here.

If `$HC_TERMINAL_ID` is set you are running inside herdr-core. If it is not, ask the user once this session whether to use hc.

Before running an `hc` command, read the manual with `hc --skill` and follow it. For the Herdr window, read `herdr-app --skill`.
